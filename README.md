# الكرنة للعطور — برنامج المحاسبة المكتبي للعطور

## التثبيت على Windows 10/11

1. شغّل `AlKarna-Perfume-Setup-x64.exe`.
2. افتح **الكرنة للعطور** من سطح المكتب أو قائمة ابدأ.
3. سجّل الدخول:

- اسم المستخدم: **المالك**
- كلمة المرور: **12345678**

يعمل البرنامج دون إنترنت ودون تثبيت Node.js أو MongoDB أو SQLite أو أي خدمة خادم.

## مكان البيانات

نسخة العطور مستقلة عن نسخة الكرنه الأصلية. توجد قاعدة بياناتها عادةً في:

`C:\Users\<USER>\AppData\Roaming\AlKarna-Perfume\data\alkarna-perfume.sqlite`

لذلك يمكن تثبيت وتشغيل **الكرنه** و**الكرنة للعطور** على نفس الجهاز دون مشاركة قاعدة البيانات.

**لا تحذف ملف قاعدة البيانات يدويًا.** التحديثات لا تمس مجلد بيانات المستخدم. احتفظ بنسخ احتياطية دورية.

> الإصدار غير موقّع رقميًا حاليًا، لذلك قد يعرض Windows SmartScreen تنبيهًا عند أول تثبيت.
